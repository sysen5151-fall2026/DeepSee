# clinician_interface/

Boundary element: **Clinician** — the reviewing physician at the workstation.

What crosses this boundary is defined in [`docs/context.md`](../docs/context.md):
credentials, a radiograph, patient context and a review decision in; a ranked
differential, evidence trail, attention overlay and exported PDF out.

**No code lives here yet.** The working implementation is `frontend/app/` and
`frontend/components/ui/`. This directory is the traceability anchor for the
Chapter 7 interface contract for this boundary.
